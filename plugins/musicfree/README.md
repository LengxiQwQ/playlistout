# 把你的歌单带走 — MusicFree 插件使用手册

> **一键跨平台歌单导入插件：歌单解析 + 原生音源路由 + 内置兜底音源（电脑版 & 手机版通用）**  
> 官方网站：[playlistout.lengxiqwq.com](https://playlistout.lengxiqwq.com)

「把你的歌单带走」是专为 [MusicFree](https://musicfree.catcat.work/) 打造的歌单解析与导入插件。
**本插件以歌单解析为核心，播放优先交给原生音源插件**：解析出的每一首曲目都会按「原曲自然平台」归属（网易云 / QQ音乐 / 酷狗 / 酷我 / 汽水 / 咪咕 / B站），由您设备上已安装的对应原生音源插件负责播放与歌词，直接复用其音源能力；在此之上内置「兜底音源引擎」作为最后防线，确保历史歌单与缺源场景依然能播。
- **电脑端（稳定版）**：支持一键浏览选文件弹窗、拖拽 `.json`、本地路径导入；若原平台插件缺失或取源失败，会先跨插件严格匹配同一首原曲换源续播（同名 + 同歌手 + 同版本 + 时长吻合，宁可跳过绝不播放错歌），再自动启用内置兜底音源作最后防线，并弹出轻量提示；
- **手机端**：支持全平台在线链接一键解析，导入曲目自动分流至手机上已安装的原生音源插件；原生插件缺源时同样会启用内置兜底音源严格匹配播放。酷狗歌单可在设置中填入 Token，直接粘贴链接全量解析！

## 📥 安装指南（电脑版 & 手机版）

1. 打开 **MusicFree**（电脑端或手机端均可），进入 **「插件设置」**。
2. 点击 **「从网络安装插件」**（或右下角加号）。
3. 复制并粘贴以下插件官方地址，点击确认安装：
   ```text
   https://playlistout.lengxiqwq.com/plugins/musicfree/把你的歌单带走-PlaylistOut.js
   ```

## 📖 使用教程

### 1. 在线歌单链接导入（电脑端 & 手机端通用）

1. 在音乐 App（QQ音乐、网易云、汽水、酷狗等）中复制**歌单分享链接**。
2. 进入 MusicFree 侧边栏，点击 **「导入外部歌单」**。
3. 导入插件选择 **「把你的歌单带走」**。
4. 粘贴歌单链接，点击 **「确认/解析」**。
5. 解析完成后勾选歌曲，即可生成播放歌单。

### 2. 本地 JSON 歌单文件导入（电脑端）

1. 前往 [PlaylistOut 官网](https://playlistout.lengxiqwq.com)，登录并解析歌单。
2. 点击 **「导出 JSON」** 保存歌单文件到本地。
3. 打开电脑端 MusicFree 的 **「导入外部歌单」** 弹窗，选择「把你的歌单带走」：
   - 点击输入框下方的 **「📂 选择本地 JSON」** 按钮选取文件，或直接将 `.json` 文件拖入弹窗；亦可直接输入本地文件路径（如 `D:\my_playlist.json`）。
4. 导入完成后即可查看歌曲列表并直接播放。

在 MusicFree 的「插件设置」中，点击本插件右侧的**齿轮图标**即可配置：

| 设置项 | 变量名 | 默认值 | 作用与说明 |

## 🔒 匿名活跃统计说明

本插件被播放器**加载时会静默发送一次匿名心跳**（每个设备每天最多一次，电脑端记录本地标记、重启不重发；无任何弹窗、提示或设置开关）：

- 心跳内容仅为 `{"type":"active"}`，不包含歌单、账号、Token、设备标识等任何用户数据；
- 请求头携带与服务端解析歌单时相同的客户端声明信息（客户端类型 / 版本 / 设备大类 / 系统），服务端仅据此记录渠道、客户端版本、国家/地区、小时与当日去重哈希（匿名单向哈希，7 天过期）；
- 用于统计「把你的歌单带走」各端的每日活跃规模，属于与官网访问统计同级的匿名聚合指标；
- 希望关闭时，卸载插件或屏蔽本插件对 `playlistout-api.lengxiqwq.com` 的网络请求即可（不影响歌单解析、导入与播放功能）。

## ❓ 常见问题 (FAQ)

**Q：导入后歌曲能正常播放和加载歌词吗？**  
A：播放与歌词优先使用您设备上已安装的原生音源插件（如网易云、QQ音乐等），建议先装好对应插件。  
在此之上本插件提供「双层兜底」：电脑端稳定版会在原平台插件缺失或取源失败时，依次在其它已安装插件中严格匹配「同名 + 同歌手 + 同版本 + 时长吻合」的原曲自动换源；仍无果（以及手机端原生插件缺源）时，自动调用内置兜底音源（QQ音乐 / 网易云音乐 / 酷狗音乐，支持无损 / 320k 优先）严格匹配原曲恢复播放，歌词同样支持兜底获取。任何一级匹配不到完全一致的原曲都会跳过并提示，宁可不播也不播放错歌。

**Q：之前老版本导入的歌单还能播吗？**  
A：可以。历史版本导入的曲目在播放时会自动识别其原平台身份：能精确取链的直接播放，取不到的依次走跨插件严格匹配兜底与内置兜底音源，无需重新导入。

**Q：内置兜底音源覆盖哪些平台？**  
A：目前覆盖 QQ音乐、网易云音乐、酷狗音乐三家的公开接口（QQ / 网易支持无损与 320k 优先，酷狗支持免费曲目）。酷我、咪咕、B站、汽水音乐暂无稳定公开取链通道，这些平台的缺源曲目会自动跳过；各平台 VIP / 付费曲目能否取链取决于其公开接口返回情况，取不到时同样自动跳过，绝不使用来路不明的音源。

**Q：酷狗音乐为什么在客户端内只解析出前 10 首？**  
A：酷狗官方对未登录接口有严格限制。最推荐的做法是前往 [PlaylistOut 官网](https://playlistout.lengxiqwq.com) 登录解析并导出 JSON 文件导入；也可以在插件设置中填入官网复制的酷狗 Token。

**Q：遇到链接解析失败或网络超时怎么办？**  
A：部分音乐平台会动态调整接口或增加风控。请先确认链接为公开歌单且网络畅通；若确属接口失效，欢迎在 [GitHub Issues](https://github.com/LengxiQwQ/playlistout/issues) 提交反馈。

## 💻 技术架构与实现原理（开发者参考）

本插件遵循 MusicFree 插件开发标准，针对歌单迁移场景进行了多项底层优化与架构设计：

### 1. 原生平台路由与双层自动兜底 (Native Platform Routing & Two-Layer Auto Rescue)
- **定位分离**：PlaylistOut 专注于歌单结构解析与元数据标准化；播放优先交给设备上的原生音源插件，内置兜底音源仅作为客户端本地的最后防线，不经任何 PlaylistOut 服务器转发。
- **元数据注入**：`importMusicSheet` 解析每首歌时自动识别来源平台，曲目 `platform` 直接归属原生平台标识，并注入 `_originPlatform` 与原生取链字段（QQ音乐 `songmid`、网易云 `track.id`、酷狗 `hash`、酷我 `rid`、汽水 `trackId`、咪咕 `contentId`、B站 `bvid` 等）。
- **宿主属性保护**：通过访问器拦截曲目 `platform` 属性，阻止 MusicFree 宿主导入后 `resetMediaItem(item, plugin.name)` 把平台归属改写成本插件名，确保播放/歌词请求始终分发给正确的原生插件（序列化后自动转为普通值，跨端存储安全）。
- **第一层 · 自动兜底换源（桌面稳定版）**：拦截宿主自身的插件调用通道 `@shared/plugin-manager/call-plugin-method`，当任意平台曲目取源/取词失败且曲目由本插件导入时，按「原平台 -> 主流平台 -> 其余已安装插件」顺序搜索，并执行 100% 严格匹配（歌名归一化相等 + 版本标签一致 + 歌手精确相等 + 时长偏差 ≤ 12 秒）后才回传音源；命中弹「音源：X」提示，全程无匹配则提示跳过。匹配结果与失败均带短期缓存，避免音质切换重复搜索。
- **第二层 · 内置兜底音源引擎（v2.1.3，电脑端 & 手机端通用）**：当跨插件通道不可用或无果时，自动调用内置兜底通道：QQ音乐（vkeys 直链，无损 / 320k / 128k 按请求音质自动降级）、网易云音乐（GD Studio 直链含无损 + Meting 302 兜底）、酷狗音乐（官方搜索 + getSongInfo 免费曲直链，付费灰歌自动跳过）。所有候选执行与第一层同级的 100% 严格匹配；媒体直链一律经域名白名单校验（仅 QQ音乐 / 网易云 / 酷狗 CDN 与 Meting 跳转地址）；失败按 60 秒负缓存去重，严格匹配结果 30 分钟复用（含歌词复用）。网易云 VIP 曲目只拿得到 30 秒试听片段的场景会被识别（`jd-musicrep-ts` 标记 + 字节数校验），不会被误当完整曲：先继续匹配其它平台的完整版，全部无果时才兜底播放试听并提示「X仅试听30秒」。内置层提示会附上实际取链的接口服务名（如「内置音源：QQ音乐（VKeys）」），接口出处见下文致谢表。
- **兜底边界（如实说明）**：内置兜底目前覆盖 QQ音乐 / 网易云音乐 / 酷狗音乐；酷我（风控 + 广告音源风险）、咪咕 / 汽水（上游接口不可用）、B站（Referer 反爬）暂无内置通道，这些平台的缺源曲目会自动跳过。各平台 VIP / 付费曲目能否取链取决于公开接口返回情况。
- **历史歌单兼容**：旧版本导入的品牌曲目（`platform` 仍为插件名）在播放时会先尝试原平台精确取源（`_originPlatform` / 历史 ID 前缀 / `_src` 凭证），再依次走跨插件兜底与内置兜底音源，无需重新导入。

### 2. 沙箱穿透与桌面端增强 (Desktop Enhancements)
- **环境适配**：MusicFree 桌面端（Electron 环境）将插件运行于隔离沙箱中，常规 `require('fs')` 会返回 `null` 且 `process.mainModule` 为 `undefined`。
- **底层穿透**：插件利用原生 ESM dynamic `import('module')` 拿到 Node 底层 `Module._load`，安全按需加载真实的 `fs`、`path` 与 `electron` 模块。
- **桌面端交互增强**：
  - 支持直接唤起操作系统原生文件选择器，导入本地 `.json` 歌单文件；
  - 自动向主窗口 WebContents 注入轻量交互脚本，在导入弹窗中添加「📂 选择本地 JSON」与「🌐 去官网解析」虚线按钮，并支持直接拖拽 `.json` 文件导入；
  - 在客户端顶部提供轻量状态通知（Toast），遇到受限或无源情况时友好引导。

### 3. 多端一致的原生路由 (Unified Native Routing Across Hosts)
- **环境嗅探**：通过 `isHostElectron()` 动态检测运行环境。电脑端为 Electron 环境，具备 Node.js 宿主集成；手机端（Android）为 React Native / Hermes 隔离沙箱环境。
- **路由一致**：无论电脑端还是手机端，导入曲目的 `platform` 都归属为原曲自然平台（如 `netease` / `qq` / `kugou` / `kuwo` / `qishui` / `migu` 等），并注入 `_src` 原生取链凭证；点击播放或加载歌词时由 MusicFree 宿主直接调度对应原生插件，跨端体验一致、零额外开销；缺源时由本插件的两层兜底链接管。
- **桌面增强**：桌面稳定版额外安装宿主通道桥接（跨插件自动兜底换源）并启用轻量桌面 Toast；桌面测试版 / 手机端宿主未提供该通道，跨插件兜底会安全跳过，由内置兜底音源接管。无法识别来源的曲目会归属于本插件平台，播放时由两级兜底链尝试自动搜源。

### 4. Android Hermes 引擎语法兼容
- Android 版 MusicFree 运行在 Hermes JavaScript 引擎上，部分历史 Hermes 版本对 ES2020+ 的 `?.` (可选链)、`??` (空值合并运算符) 以及 `async () =>` (异步箭头函数) 存在严格语法限制。
- 本插件经全面重构，保证全量代码 100% 遵循 Hermes 兼容的 ES6 标准语法，消除任何潜在移动端 `SyntaxError: Unexpected token`。
