# 把你的歌单带走 — MusicFree 插件使用手册

> **一键跨平台歌单导入插件：纯歌单解析 + 原生音源路由（电脑版 & 手机版通用）**  
> 官方网站：[playlistout.lengxiqwq.com](https://playlistout.lengxiqwq.com)

「把你的歌单带走」是专为 [MusicFree](https://musicfree.upup.fun/) 打造的歌单解析与导入插件。
**本插件只解析歌单，不自带任何音源**：解析出的每一首曲目都会按「原曲自然平台」归属（网易云 / QQ音乐 / 酷狗 / 酷我 / 汽水 / 咪咕 / B站），由您设备上已安装的对应原生音源插件负责播放与歌词，直接复用其音源能力。
- **电脑端（稳定版）**：支持一键浏览选文件弹窗、拖拽 `.json`、本地路径导入；若原平台插件缺失或取源失败，会自动跨插件严格匹配同一首原曲换源续播（同名 + 同歌手 + 同版本 + 时长吻合，宁可跳过绝不播放错歌），并弹出轻量提示；
- **手机端**：支持全平台在线链接一键解析，导入曲目自动分流至手机上已安装的原生音源插件；播放兜底能力取决于手机端宿主的换源机制。酷狗歌单可在设置中填入 Token，直接粘贴链接全量解析！

## 📥 安装指南（电脑版 & 手机版）

1. 打开 **MusicFree**（电脑端或手机端均可），进入 **「插件设置」**。
2. 点击 **「从网络安装插件」**（或右下角加号）。
3. 复制并粘贴以下插件官方地址，点击确认安装：
   ```text
   https://playlistout.lengxiqwq.com/plugins/musicfree/把你的歌单带走-PlaylistOut.js
   ```

## 📖 使用教程

### 1. 在线歌单链接导入（电脑端 & 手机端通用）

1. 在音乐 App（QQ音乐、网易云、汽水、酷狗等）中复制**歌单分享链接**。
2. 进入 MusicFree 侧边栏，点击 **「导入外部歌单」**。
3. 导入插件选择 **「把你的歌单带走」**。
4. 粘贴歌单链接，点击 **「确认/解析」**。
5. 解析完成后勾选歌曲，即可生成播放歌单。

### 2. 本地 JSON 歌单文件导入（电脑端专属，解决酷狗限制）

1. 前往 [PlaylistOut 官网](https://playlistout.lengxiqwq.com)，登录并解析歌单。
2. 点击 **「导出 JSON」** 保存歌单文件到本地。
3. 打开电脑端 MusicFree 的 **「导入外部歌单」** 弹窗，选择「把你的歌单带走」：
   - 点击输入框下方的 **「📂 选择本地 JSON」** 按钮选取文件，或直接将 `.json` 文件拖入弹窗；亦可直接输入本地文件路径（如 `D:\my_playlist.json`）。
4. 导入完成后秒级呈现全部歌曲（纯离线解析，不受字符长度限制，零流量消耗）。

## ⚙️ 插件设置说明

在 MusicFree 的「插件设置」中，点击本插件右侧的**齿轮图标**即可配置：

| 设置项 | 变量名 | 默认值 | 作用与说明 |
| :--- | :--- | :--- | :--- |
| **酷狗 Token** | `kugouToken` | *(留空)* | *(可选)* 填入官网登录后复制的 Token，可免本地导出 JSON 直接在客户端内解析完整酷狗歌单 |
| **酷狗 UserID** | `kugouUserid` | *(留空)* | *(可选)* 酷狗用户 ID（若在 Token 中已包含 `token:userid` 则无需填写） |

> 已移除「音源通道」「换源策略」等旧设置项：本插件不再内置任何音源，播放一律交给原生插件；电脑端稳定版会在原平台无源时自动跨插件严格匹配换源。

## ❓ 常见问题 (FAQ)

**Q：导入后歌曲能正常播放和加载歌词吗？**  
A：本插件只负责解析歌单，并把每首曲目归属到正确的原生平台。播放与歌词依赖您设备上已安装的原生音源插件（如网易云、QQ音乐等），请先装好对应插件。  
电脑端（稳定版）额外提供自动兜底：原平台插件缺失或该曲目取源失败时，会依次在其它已安装插件中严格匹配「同名 + 同歌手 + 同版本 + 时长吻合」的原曲并自动换源；匹配不到则跳过并提示，宁可不播也不播放错歌。手机端是否具备类似兜底取决于手机端宿主的换源设置。

**Q：酷狗音乐为什么在客户端内只解析出前 10 首？**  
A：酷狗官方对未登录接口有严格限制。最推荐的做法是前往 [PlaylistOut 官网](https://playlistout.lengxiqwq.com) 登录解析并导出 JSON 文件导入；也可以在插件设置中填入官网复制的酷狗 Token。

**Q：遇到链接解析失败或网络超时怎么办？**  
A：部分音乐平台会动态调整接口或增加风控。如遇解析失败，请前往官网尝试解析，或在 GitHub 提交 Issue 反馈。

## 💻 技术架构与实现原理（开发者参考）

本插件遵循 MusicFree 插件开发标准，针对歌单迁移场景进行了多项底层优化与架构设计：

### 1. 原生平台路由与自动兜底 (Native Platform Routing & Auto Rescue)
- **定位分离**：PlaylistOut 专注于歌单结构解析与元数据标准化，**不提供、不内置任何音源直链**。
- **元数据注入**：`importMusicSheet` 解析每首歌时自动识别来源平台，曲目 `platform` 直接归属原生平台标识，并注入 `_originPlatform` 与原生取链字段（QQ音乐 `songmid`、网易云 `track.id`、酷狗 `hash`、酷我 `rid`、汽水 `trackId`、咪咕 `contentId`、B站 `bvid` 等）。
- **宿主属性保护**：通过访问器拦截曲目 `platform` 属性，阻止 MusicFree 宿主导入后 `resetMediaItem(item, plugin.name)` 把平台归属改写成本插件名，确保播放/歌词请求始终分发给正确的原生插件（序列化后自动转为普通值，跨端存储安全）。
- **自动兜底换源（桌面稳定版）**：拦截宿主自身的插件调用通道 `@shared/plugin-manager/call-plugin-method`，当任意平台曲目取源/取词失败且曲目由本插件导入时，按「原平台 -> 主流平台 -> 其余已安装插件」顺序搜索，并执行 100% 严格匹配（歌名归一化相等 + 版本标签一致 + 歌手精确相等 + 时长偏差 ≤ 12 秒）后才回传音源；命中弹「已自动从「X」为您匹配播放」提示，全程无匹配则提示跳过。匹配结果与失败均带短期缓存，避免音质切换重复搜索。
- **历史歌单兼容**：旧版本导入的品牌曲目（`platform` 仍为插件名）在播放时会先尝试原平台精确取源（`_originPlatform`），再走上述兜底链。

### 2. 沙箱穿透与桌面端增强 (Desktop Enhancements)
- **环境适配**：MusicFree 桌面端（Electron 环境）将插件运行于隔离沙箱中，常规 `require('fs')` 会返回 `null` 且 `process.mainModule` 为 `undefined`。
- **底层穿透**：插件利用原生 ESM dynamic `import('module')` 拿到 Node 底层 `Module._load`，安全按需加载真实的 `fs`、`path` 与 `electron` 模块。
- **桌面端交互增强**：
  - 支持直接唤起操作系统原生文件选择器，秒级导入本地 `.json` 歌单文件；
  - 自动向主窗口 WebContents 注入轻量交互脚本，在导入弹窗中添加「📂 选择本地 JSON」与「🌐 去官网解析」虚线按钮，并支持直接拖拽 `.json` 文件导入；
  - 在客户端顶部提供轻量状态通知（Toast），遇到受限或无源情况时友好引导。

### 3. 多端一致的原生路由 (Unified Native Routing Across Hosts)
- **环境嗅探**：通过 `isHostElectron()` 动态检测运行环境。电脑端为 Electron 环境，具备 Node.js 宿主集成；手机端（Android）为 React Native / Hermes 隔离沙箱环境。
- **路由一致**：无论电脑端还是手机端，导入曲目的 `platform` 都归属为原曲自然平台（如 `netease` / `qq` / `kugou` / `qishui` 等），并注入 `_src` 原生取链凭证；点击播放或加载歌词时由 MusicFree 宿主直接调度对应原生插件，跨端体验一致、零额外开销。
- **桌面增强**：桌面稳定版额外安装宿主通道桥接（自动兜底换源）并启用轻量桌面 Toast；桌面测试版 / 手机端宿主未提供该通道，插件会安全跳过，退化为纯解析器。无法识别来源的曲目会归属于本插件平台，桌面端由兜底链尝试自动搜源。

### 4. Android Hermes 引擎语法兼容
- Android 版 MusicFree 运行在 Hermes JavaScript 引擎上，部分历史 Hermes 版本对 ES2020+ 的 `?.` (可选链)、`??` (空值合并运算符) 以及 `async () =>` (异步箭头函数) 存在严格语法限制。
- 本插件经全面重构，保证全量代码 100% 遵循 Hermes 兼容的 ES6 标准语法，消除任何潜在移动端 `SyntaxError: Unexpected token`。
