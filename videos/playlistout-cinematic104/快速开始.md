# Playlist Out 电影感宣传片 · 快速开始

1. 先观看 `out/PlaylistOut_Cinematic_Journey104_1080p.mp4`（104 秒、1080p、30fps、含音乐）。
2. 打开 `previews/QA_contact_*.jpg` 查看每段及转场截图。
3. 在 `docs/CINEMATIC_REVISION.md` 查看相机轨迹、转场与节拍修改。
4. 要修改字幕/节奏/物体轨迹，编辑 `src/scene.ts`，全部按帧生成。
5. 要修改音乐，编辑 `scripts/generate_music.py`；两条音频分轨在 `public/audio/`。

在联网的 Node.js 环境中执行 `npm install && npm run studio`，或使用 README 的离线渲染命令。

**本次视频由已验证的 TypeScript SVG/CairoSVG/FFmpeg 路线生成。Remotion 同源工程交付，但此环境未验证 Remotion CLI。**
