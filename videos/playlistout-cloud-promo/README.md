## 一、作品概述与核心特色

本片是一部为开源项目 **Playlist Out（把你的歌单带走）** 打造的 58 秒动画电影质感产品宣传短片。  
以官方吉祥物——**晴空蓝「小困云」音符精灵** 为全片绝对主角，串联起从“平台受困”到“自由带走”的完整冒险故事。

### 核心亮点
1. **电影级手账拼贴美学**：温暖纸浆纤维底色、活页打孔环、横线笔记本页、半透明彩色和纸胶带与柔和硬边投影。
2. **120 BPM 节奏驱动与魔性抖动 (Meme Beat Jitter)**：
   - 音乐与动作帧级卡点（1 拍 = 15 帧 = 0.5s，每小节 60 帧 = 2.0s）。
   - 小困云在音乐重拍命中瞬间触发表情包式的高速压缩与回弹微震，充满动感与喜感！
3. **专属无遮挡表演走廊**：
   - 遵循 Windows 200% 缩放与手机横屏（844px）阅读原则，标题 54px–88px，表格正文 22px–25px。
   - 小困云拥有独立观景露台、卡片桥梁与控制台，绝不遮挡任何曲目或文件名。
4. **诚实客观的功能表达**：
   - 支持 QQ 音乐、网易云音乐、酷狗音乐、酷我音乐、汽水音乐、咪咕音乐 6 大平台。
   - 突出双工作表 Excel（曲目清单 + 歌单元数据）与标准 Canonical JSON 两大王牌格式。
   - 展现批量多 Sheet 合并、独立 ZIP 封箱、本地独立 CLI 单文件、第三方播放器（MusicFree、洛雪、Listen 1、BBPlayer）生态流动。
   - 严守宪法红线：绝不宣称“零版权风险”，不涉及音频下载，纯端侧隐私安全。

## 三、快速构建与 QA

```bash
# 进入工程目录
cd D:\Projects\playlistout\videos\playlistout-cloud-promo

# 静态类型检查
npm run typecheck

# 重新生成 120 BPM 原创配乐与拟音分轨
python tools/make_score.py

# 渲染 1080p 60fps/30fps 广播级成片 MP4
npm run render

# 运行自动化媒体质量检测与图集生成
python tools/qa.py
```

## 四、技术参数

- **分辨率**：1920 × 1080 (16:9 FHD)
- **帧率**：30.0 fps (精确 1740 帧 / 58.000 秒)
- **视频编码**：H.264 (yuv420p, CRF 16, High Profile)
- **音频编码**：AAC 320 kbps 立体声 / 48 kHz
- **响度达标**：符合 EBU R128 标准（-16.0 LUFS 广播级响度，真峰值 ≤ -1.0 dBTP）
