# Playlist Out 宣传片 v4 — 目标与轮次

## 总目标

把宣传片从“桌面截图缩到手机”改成“按手机观看重新排版的纸片动画”：

- 主标题保持现有大小，不放大。
- 其他 UI 元素、文字、按钮、行高、卡片一起放大，按 1.75× 逻辑 UI 起步，手机横屏实看调整。
- 不用全局镜头推进；缩放是静态的 UI 设计尺度，不是画面 zoom。
- 转场恢复接近 v1 的连贯感，不用页码、STEP、全屏翻页。
- 粉色猫耳音符按用户设定图重做，能真实伸手点击，并跟随 120 BPM 鼓点。
- 最后再抠构图、纸张、节奏和微小细节，统一渲染和 QA。

## 轮次

### 第 1 轮：尺度与全片铺开（已完成）

v4 已按 1.75× 重排全部 UI 场景并完成 58 秒实际渲染；主标题不动，字体恢复。
验收：0 黑帧、0 静态区间、完整解码，手机宽 844px 抽帧见 `qa/phone-sheet-v4.jpg`。

交付：

- `src/scale.ts`：`UI_SCALE = 1.75`、`u()`、手机宽度检查基准。
- `ScaleLab` 独立 composition：不改主片，只做前两个/三个场景的尺度和排版样张。
- 1920 原尺寸样张 + 844px / 693px 手机宽对照图。
- 先确认“文字/元素大小是否合适”，确认后再铺全片。

验收：

- 844px 宽时关键文字 ≥ 12px，正文 ≥ 10px。
- 693px 宽时关键文字 ≥ 10px。
- 主标题字号不变。
- 没有用全局 scale 把整张画面 zoom。

### 第 2 轮：整体流程与转场（下一轮）

- 以 v1 的转场语言为参考，恢复纸片/元素接力的连贯感。
- 不放回页码、STEP、全屏翻页。
- 笼子重新画成真正的笼子；开头的“收音机呲呲声”换掉；不要硬切冒字。
- 逐场检查“上一场最后一眼”和“下一场第一眼”是否接得上。

### 第 3 轮：角色、鼓点与点击

- 按设定图重做粉色猫耳耳机音符：比例、猫耳、耳机、白手套、白鞋、音符符干。
- 手真正伸出、接触按钮、按下回弹，不是贴纸式假动作。
- 以 120 BPM（15 帧/拍）做踩点呼吸、踏步、起跳和落地。
- 保证任何场景不被裁切、不被卡片盖住、不消失。

### 第 4 轮：节奏、细节、最终 QA

- 按内容重排停留时间，修太短/太长。
- 导出页、表格密度、纸张、字号溢出和固定镜头构图。
- 完整 58 秒渲染、手机宽抽帧、Contact Sheet、音频和 QA 文档。

## 非目标

- 不做竖屏版本。
- 不删功能点；用重排和逐段出现容纳内容。
- 不为了“大”而把整张画面放大。
- 不在这一轮重画角色或重做转场。
