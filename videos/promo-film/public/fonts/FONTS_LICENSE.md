# 字体资源与开源许可说明 (Fonts & Licensing)

本宣传片项目将所需全部中英文手写体与等宽技术字体打包在 `public/fonts/` 目录下，通过 `@font-face` 与 `FontFace` API 离线预加载，无需联网即可确定性渲染：

| 字体家族 (`font-family`) | 本地文件 | 用途 | 开源许可证 |
|---|---|---|---|
| **Ma Shan Zheng (马善政毛笔楷书)** | `public/fonts/MaShanZheng-Regular.woff` | 中文主标题、手账大字、毛笔手写标题 | SIL Open Font License 1.1 (OFL-1.1) |
| **ZCOOL KuaiLe (站酷快乐体)** | `public/fonts/ZCOOLKuaiLe-Regular.woff` | 手账中文标注、贴纸、按钮、趣味批注 | SIL Open Font License 1.1 (OFL-1.1) |
| **Permanent Marker** | `public/fonts/PermanentMarker-Regular.woff` | `Playlist Out` 品牌标志与英文马克笔标题 | Apache License 2.0 |
| **Caveat (Bold 700)** | `public/fonts/Caveat-Bold.woff` | 英文手写副标题与手账花体批注 | SIL Open Font License 1.1 (OFL-1.1) |
| **Space Mono (Regular 400 / Bold 700)** | `public/fonts/SpaceMono-Regular.woff`, `SpaceMono-Bold.woff` | 歌单链接、CLI 终端、JSON 代码与统计数字 | SIL Open Font License 1.1 (OFL-1.1) |
