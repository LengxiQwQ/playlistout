## 2. 主角设定还原度与全片连续叙事核查

参照用户提供的 **`音符小助手 ♫ 角色设定图 v1.0`**（保存于 `references/mascot-design-sheet.jpg`），在 `src/components/PinkNoteMascot.tsx` 与 `src/components/MascotDirector.tsx` 中实现了全片 1740 帧不间断的角色驱动表演：

1. **造型与材质还原**：
   - **主体形象**：圆润粉色八分音符脑袋，右上方延伸出粗壮可爱的粉色音符符干与飘扬符尾。
   - **标志性配饰**：奶油粉白拼色猫耳头戴式耳机，左右耳罩外侧均印有粉色猫爪肉垫图案。
   - **五官与肢体**：闪亮深棕色大眼睛 + 腮红 + 丰富嘴部表情（无鼻子设计，严格对齐角色设定图），搭配白色圆手套与粉白运动小鞋，外圈带有贴纸白边与蜡笔手绘质感。
2. **物理感与帧级动作编排（`MascotDirector.tsx`）**：
   - 全片采用抛物线跳跃轨迹 (`4 * t * (1 - t)`) + 起跳/落地挤压拉伸 (`squash & stretch`) + 随 120 BPM 节拍呼吸律动 (`beatBounce`)。
   - **Scene 1（0.0s–8.6s，被困与破笼）**：小音符被困在六大音乐平台围成的铁笼里委屈流泪、双手抓栏杆摇晃 → 金色钥匙旋转飞入，“咔哒”打开红锁，笼门向两侧弹开 → 小音符高高跃出笼子，稳稳落在 `Playlist Out` 主品牌卡与六大平台贴纸旁。
   - **Scene 2（8.2s–18.0s，网页解析歌单）**：小音符跳到黄色便利贴输入框旁引导粘贴链接 → 高高跃起踩下蓝色「解析」按钮（按钮产生真实按压回弹与波纹） → 104 首歌曲列表与 VIP/正常状态标签顺滑展开，小音符在右侧粉色专属舞台挥动小指挥棒展示结果，随后跳起按下右上角「导出 Excel」按钮。
   - **Scene 3（17.6s–27.4s，多格式本地导出）**：歌单卡片一分为二展开为双工作表 **Excel (`.xlsx`)** 与标准 **Canonical JSON (`.json`)** 卡片，底部铺开 `Excel / JSON / CSV / TXT / M3U8 / Markdown` 六大格式手账卡；小音符在卡片之间的中央连廊跳跃欢呼。
   - **Scene 4（27.0s–36.0s，批量整理与打包）**：小音符依次跳落勾选 3 张公开歌单（共 151 首） → 跳下踩中橙色「批量打包导出」按钮 → 右侧展开 **方式 A：多工作表合并 Excel** 与 **方式 B：独立文件一键打包 ZIP**，小音符站在拉链右侧拉动金色 `ZIP` 拉链头完成封口。
   - **Scene 5（35.6s–46.0s，本地 CLI 命令行世界）**：小音符跳进黑板纸质感的 `Windows PowerShell · playlistout (CLI v3.0.0)` 终端右侧舞台，抱起浅蓝色迷你笔记本电脑（还原设定图“使用电脑”动作）敲击输入 → 跃起踩下巨大的黄色 `Enter ↵` 实体键帽，触发 `.xlsx` 与 `.json` 导出完成提示及底部 `Windows / macOS / Linux / npm` 跨平台徽章。

## 3. “Windows 200% 缩放”与手机横屏 (`844px`) 可读性检验

针对“手机横屏观看时不能字太小、信息太密，也不允许吉祥物或气泡遮挡正文”的核心要求，我们在 `qa/mobile-844px-readability.jpg` 中将 6 个核心场景下采样至 `844 × 474` 像素进行逐一核验：

1. **大字号聚焦排版**：
   - 全片主标题 `46px–68px`，卡片标题 `30px–38px`，表格与终端正文 `20px–26px`，状态徽章 `18px–22px`。
   - 坚决摒弃整页缩小塞入画面的做法，每一幕只聚焦当前阶段最核心的 1–2 个手账容器。
2. **零遮挡舞台分区（Zero-Overlap Stage Design）**：
   - 为吉祥物在每一幕预留了专属落脚区（如笼内加宽中缝 `x=255..415` 与下置锁头 `y=492`、网页解析右侧粉色虚线舞台、多格式导出双卡中央连廊、批量导出 ZIP 右侧独立区、CLI 右侧米白操作台、生态卡片右下留白区），确保 **100% 正文、表头、文件名与状态徽章不被遮挡、不发生异常折行**。

## 5. 已知局限与后续可迭代方向

1. **程序化合成原声**：当前配乐与音效由 `tools/make_score.py` 纯 Python 确定性合成（零外部版权依赖，节拍与帧号 100% 同步）。若后续用于大型发布会展映，可在保持 `src/timeline.json` 时间轴不变的前提下，将真实乐器实录分轨替换至 `public/audio/soundtrack.wav`。
2. **矢量 SVG 角色动画**：当前粉色音符小助手由矢量多层 SVG + 蜡笔噪点滤镜实时渲染，支持无限分辨率缩放与帧级参数控制；若未来希望增加 3D 转头透视，可在此骨骼基础上扩展 3/4 侧面帧切换。
