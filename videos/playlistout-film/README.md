## 三、视觉与「Windows 200% 缩放」手机端可读性设计

针对移动端横屏观看场景，本片摒弃「把完整电脑网页缩小塞进 1080p」的做法，全面采用**局部聚焦 + 200% 逻辑放大排版**：
- **主标题与章节大字**：`56px – 96px`
- **卡片标题、输入框网址、按钮文字**：`28px – 42px`
- **曲目表正文、CLI 终端命令行、JSON 代码**：`21.5px – 28px`
- **辅助角标与说明胶囊**：严格控制在 `19px – 24px` 以上（全片零 `8px–12px` 微小字）。

## 四、渲染与复现方法

### 环境要求
- **Node.js** ≥ 20
- **Google Chrome**（或 Chromium）
- **Python** ≥ 3.10 + `numpy` + `ffmpeg`（用于合成配乐与执行自动化 QA）

### 常用命令

```bash
cd videos/playlistout-film

# 1. 类型检查
npm run typecheck

# 2. 重新合成 58 秒原创配乐与音效 (输出至 public/audio/)
npm run audio

# 3. 打开 Remotion Studio 交互预览
npm run studio

# 4. 渲染关键帧预览图 (输出至 qa/stills/)
npm run stills

# 5. 渲染最终 1080p H.264 成片 (输出至 output/playlistout-promo.mp4)
npm run render

# 6. 运行自动化质量检查、抽帧与 Contact Sheet 生成
npm run qa
```
