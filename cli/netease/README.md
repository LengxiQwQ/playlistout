## 网易云音乐歌单导出工具

用于抓取 网易云音乐 歌单及用户自建歌单信息，并导出为常见格式（支持标记歌曲状态：正常、下架/无版权、VIP专享、付费专辑）。

作者：`lengxiQwQ`

---

### 功能特性

- 支持通过网易云歌单链接、短链接 (`163cn.tv`) 或 歌单 ID 输入；
- 支持输入网易云个人主页链接或用户 UID，批量导出该用户所有公开歌单；
- **独家支持歌曲状态标记**：直观区分歌曲是正常可播、下架/无版权变灰、还是 VIP专享；
- 支持全量歌曲分批详情获取，彻底突破官方未登录 10 首歌的截断限制；
- 支持导出格式：`.xlsx`、`.json`、`.txt`、`.csv`、`.m3u8`；
- **统一遵循 Canonical JSON 规范**：导出的 JSON 采用 PlaylistOut 通用歌单结构，包含歌单封面直链 (`coverUrl`) 及每首歌曲/专辑封面直链 (`coverUrl`)、统一歌手字段 `artist`、毫秒时长 `durationMs`，便于第三方播放器与自动化脚本标准化接入；
- 导出完成后（在 Windows）自动打开文件所在目录并选中文件。

---

pip install -r requirements.txt
